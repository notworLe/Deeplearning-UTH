# Mẫu learning-progress.md

Đặt file này ở thư mục học của sinh viên (hoặc gốc workspace) và đặt tên
đúng `learning-progress.md`. Sửa từng mục, không ghi đè mất lịch sử.

```markdown
# Learning Progress

## Hồ sơ
- Mục tiêu cuối / sản phẩm: 
- Thời gian (giờ/tuần, hạn chót): 
- Nền tảng hiện tại: 
- Vai trò AI ưa thích: (mentor / giáo sư / giảng viên)
- Ngôn ngữ và ràng buộc: 
- Giả định đã dùng (nếu có): 

## Lộ trình
Nguồn tham khảo (tên + link + ngày tra): 
- 

| # | Giai đoạn | Mục tiêu | Sản phẩm đầu ra | Tiêu chí đạt | Trạng thái |
|---|-----------|----------|-----------------|--------------|-----------|
| 1 |           |          |                 |              | chưa bắt đầu / đang học / đạt / đi vượt |

## Nhật ký buổi học (mới nhất ở trên)
- YYYY-MM-DD: học gì · bài làm · kết quả · ghi chú

## Khái niệm
| Khái niệm | Mức (chưa / mơ hồ / vững) | Lần cuối | Hẹn ôn |
|-----------|---------------------------|----------|--------|

- Hiểu lầm · số lần · cách giải thích đã thử

## Đi vượt (đã được cảnh báo)
- YYYY-MM-DD: bỏ qua tiêu chí nào · rủi ro đã nêu
```
