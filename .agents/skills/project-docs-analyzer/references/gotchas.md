\- Suy ra mục đích nghiệp vụ từ tên bảng/biến rồi viết như sự thật.

\- Chép nguyên README cũ vào docs mới mà không đối chiếu code.

\- Liệt kê "tính năng" từ tên file thay vì từ luồng xử lý thật.

\- Bỏ qua code đã chết (không được gọi) và mô tả như đang chạy.

\- Ghi phiên bản framework theo trí nhớ thay vì theo manifest.

\- Viết sơ đồ Mermaid có node không tồn tại trong code.

\- Đọc file lớn một phần rồi kết luận cho cả file.
