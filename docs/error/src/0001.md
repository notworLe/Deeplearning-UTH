# [ERR-001] Lỗi Import & Thiếu Thư Viện Trong Các Module của `src/`

- **Status:** INVESTIGATING
- **First Seen:** 2026-11-15 19:08
- **Reported By:** Agent tự phát hiện khi kiểm toán mã nguồn `src/`
- **Affected Files / Modules:** `src/visualize.py`, `src/datasets.py`
- **Environment / Stack:** Python 3.10+, PyTorch 2.5+, Windows

---

## 1. Dấu hiệu & Thông báo Lỗi (Error Traceback / Symptom)

Khi thực hiện lệnh import `src.visualize`:
```text
Traceback (most recent call last):
  File "<string>", line 1, in <module>
    import src.visualize
  File "D:\notworLe\Desktop\gitvanhub\Deeplearning-UTH\src\visualize.py", line 8, in <module>
    from torch.utils.tensorboard import SummaryWriter
  File "...\torch\utils\tensorboard\__init__.py", line 1, in <module>
    import tensorboard
ModuleNotFoundError: No module named 'tensorboard'
```

Ngoài ra, khi rà soát tĩnh (static code analysis) trong `src/visualize.py` và `src/datasets.py`:
- Tại `src/visualize.py` dòng 13: `from src.dataset import load_raw_dataset, create_dataloader` $\rightarrow$ Tên file thực tế trong `src/` là `datasets.py` (có 's').
- Tại `src/visualize.py` dòng 14: `from src import logs` $\rightarrow$ Không tồn tại file `src/logs.py`.
- Tại `src/consoles.py` dòng 67: `print_log("Image shape", img.shape, 20)` $\rightarrow$ Khi `test_dataset` là dataset thô (chưa qua `ToTensor()`), `img` trả về là một đối tượng `PIL.Image.Image`, không có thuộc tính `.shape` (dẫn đến `AttributeError: 'Image' object has no attribute 'shape'`). Thuộc tính đúng là `.size` hoặc chuyển sang numpy array trước khi truy cập `.shape`.
- Tại `src/datasets.py` dòng 47-49:
  ```python
  def load_train_val_test(dataset, root, p_train_transform, p_test_transform):
      v_train, v_test = load_raw_dataset(dataset, root, p_train_transform, p_test_transform)
      pass
  ```
  Hàm chưa hoàn thiện và trả về `None`.

---

## 2. Nguyên nhân Gốc rễ (Root Cause)
1. Thư viện `tensorboard` chưa được cài đặt trong môi trường hiện tại, khiến dòng import `SummaryWriter` ở đầu `src/visualize.py` làm crash toàn bộ module khi được import.
2. Lệch tên module giữa `src.dataset` và `src.datasets`.
3. Thiếu module `src.logs`.
4. Hàm `load_train_val_test` đang ở trạng thái phác thảo dở dang (`pass`).

---

## 3. Giải pháp Khắc phục (Solution & Mitigation)
- Tuân thủ quy tắc tại `.agents/rules/SRC.md`:
  - Giữ nguyên các file gốc do người dùng viết trong `src/`.
  - Tạo các script tiện ích bổ trợ riêng biệt trong thư mục `src/vibe_scripts/` (ví dụ: `src/vibe_scripts/eda_helpers.py`) để thực hiện các nghiệp vụ EDA, visualization mà không phụ thuộc vào `tensorboard` hay các dòng import lỗi của `src/visualize.py`.
- Khi người dùng refactor `src/`, khuyến nghị:
  - Bọc `from torch.utils.tensorboard import SummaryWriter` trong khối `try...except ImportError`.
  - Đổi `from src.dataset import ...` thành `from src.datasets import ...`.
  - Hoàn thiện hàm `load_train_val_test`.
